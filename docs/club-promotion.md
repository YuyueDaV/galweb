# 同好会宣传入口

首页侧栏、首页介绍区和全站页脚提供 QQ 群入口；`/about#join-club` 展示完整宣传卡和同好会 Logo。无需登录即可查看，入群方式为手机 QQ 扫码或搜索群号 **348083428**。

群号、Logo 与二维码路径集中在 `apps/web/app/data/club.ts`。素材来自维护者提供的 `澄之响2.png` 和 `qrcode_1794048674970.jpg`，原样保存到 `apps/web/public/images/club/`；后者实际为 PNG，因此站内使用 `.png` 扩展名，文件字节未重新编码。文件名包含 SHA-256 摘要以区分缓存。

宣传组件支持放大二维码、打开原图、保存入群图片和复制群号；剪贴板访问失败时显示可手动复制的群号。二维码保留完整画面和原始比例，不做滤镜、裁剪或覆盖 Logo。放大窗口使用原生 dialog，可按 Escape 关闭并返回触发按钮。

更换素材时新增文件并更新集中配置；核对二维码中展示的群号与配置一致。管理员在站点设置中填写的入社补充、联系方式和友链继续显示；默认“待管理员公布”占位内容由明确的入群入口替代。

本功能只修改前端，EdgeOne 部署新版本即可，无需迁移数据库或更新宝塔 API。
