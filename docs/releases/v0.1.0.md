# 澄之响 v0.1.0 · 首个公开版本

面向视觉小说同好会的社区网站，采用 Nuxt / Vue、NestJS 和 MySQL。

## 本版功能

- 邮箱验证码注册、登录、找回密码、账号注销与分级管理权限。
- 用户中心、头像、昵称、个性签名、个人书单和收藏。
- Markdown 发帖、多图、剧透控制、话题选择、回复、通知及管理员内容审核。
- 开放 Bangumi 搜索、作品书库管理、个人 Tier 榜及共同投票统计。
- 十二橙器提名、审核、投票、结果与归档。
- 毛玻璃界面、深色模式、手机适配及减少动态效果支持，修复 iOS 装饰星号显示。
- 管理员上传网站背景、纯色预设、浅深色配色及图片失败回退。
- EdgeOne SSR 前端与 Linux／宝塔后端部署支持。

## 下载与部署

`galweb-v0.1.0-source.zip` 和 `galweb-v0.1.0-source.tar.gz` 包含同一版本的源码；Linux／宝塔推荐 tar.gz。附件不包含已安装依赖、数据库、用户上传文件或真实配置。需要 Node.js 24、pnpm 11.25.0、MySQL 8.0，并在目标 Linux 上安装依赖和构建；不是解压即可启动的二进制程序。

校验下载文件：

```bash
sha256sum -c SHA256SUMS
```

在同一目录下载两种源码包和 RELEASE-NOTES.md 后可校验全部；仅下载一个包时，核对 SHA256SUMS 中对应的一行。

现有 Git 部署先备份数据库及上传目录，在工作区干净的 `codex/edgeone-deployment` 分支执行：

```bash
set -e
cd /www/wwwroot/galweb
pnpm --filter @chengzhixiang/api backup
git pull --ff-only origin codex/edgeone-deployment
pnpm install --frozen-lockfile
pnpm --filter @chengzhixiang/api db:check
pnpm --filter @chengzhixiang/api build
pnpm db:migrate
```

随后在宝塔重启 `galweb-api`，启动命令 `node dist/main.js`，运行目录 `apps/api`，并检查 `/api/health`。此前较旧版本缺少 Tier 等数据表，需运行迁移；保留服务器 `.env` 和上传目录。EdgeOne 从对应分支重新部署前端，按部署文档设置站点地址、API 地址及网关密钥。

使用源码包全新安装时，从 `.env.example` 创建自己的配置，再安装依赖、迁移和构建。完整说明见包内 `docs/baota-deployment.md`、`docs/edgeone-deployment.md` 和 `docs/deployment.md`。源码包不含 `.git`，后续不能直接执行 `git pull`；长期维护推荐 Git 克隆部署。

## 版本说明

首个 0.x 版本，建议先在测试环境验证注册、上传、投票和备份恢复。Bangumi 搜索依赖外部服务；封面及插画的相关权利归原权利人所有。未提供本项目对第三方素材的额外授权。

本次同时修复 SMTP 单元测试依赖本机 `.env` 的问题，测试采用独立配置和模拟邮件通道。

EdgeOne 独立验证命令在所有检查和清理完成后明确退出，并设置失败超时，避免 Linux CI 被第三方运行时后台定时器挂起。
