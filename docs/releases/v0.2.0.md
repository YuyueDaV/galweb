# 澄之响 v0.2.0 · 账号互通与评选升级

发布日期：2026 年 11 月 17 日。

本版在 v0.1.0 基础上补齐账号互通、十二橙器评选、书库与内容管理，并改进手机布局和加载体验。

## 主要更新

- **QQ／Discord 登录与绑定**：首次授权自动建号，已有账号在用户中心绑定／解绑；支持补充已验证邮箱及密码，保留至少一种可用登录或恢复方式。服务端校验授权状态，Discord 使用 PKCE；绑定冲突不会自动合并账号。
- **账号与个人空间**：支持用户名或邮箱登录、刷新后的会话恢复、统一的登录提醒弹窗；用户中心增加个人空间入口，手机资料卡与控件更清晰。
- **十二橙器完整流程**：按届次配置并推进提名、审核、投票和结果阶段；公开提名人与提名信息，同一人不能重复提名同一作品，不同成员可以共同提名；支持加权投票、名额不足时补充投票、同票加赛、结果归档与历届作品荣誉。
- **提名管理**：手动填写可附作品封面；管理员可编辑提名信息、提名人、来源和日期。第二届提供 QQ 群提名补录与同步，后续届次沿用正常流程。
- **作品与书单**：开放 Bangumi 搜索与导入、封面编辑、制作组筛选、书库排序及来源记录；完善作品与个人书单的关联，保护已提名作品并补齐缺失资料。
- **讨论与通知**：按原留言分组回复，通知提供原留言及新回复上下文并定位；管理员可编辑、删除站点通知，活动阶段变化自动通知成员。
- **界面与加载**：改善手机字号、圆润表单、下拉选择与弹窗滚动；统一加载反馈，优化首页、书库与活动数据加载。GitHub 首页新增项目预览、功能导航和部署入口。

## 升级到本版

本版需要同时更新 API 和前端，执行数据库迁移。新增或调整的账号关联、通知、提名、书库及评选表由迁移脚本处理；迁移可重复执行，不清空已有社区数据。

已有 Git 部署先备份数据库和上传目录，确认工作区干净、当前分支为 `codex/edgeone-deployment`，再执行（路径按实际部署调整）：

```bash
set -e
cd /www/wwwroot/galweb
pnpm --filter @chengzhixiang/api backup
git status --short
git branch --show-current
git pull --ff-only origin codex/edgeone-deployment
pnpm install --frozen-lockfile
pnpm --filter @chengzhixiang/api db:check
pnpm --filter @chengzhixiang/api build
pnpm db:migrate
```

保留服务器的 `apps/api/.env`、上传文件和数据库。随后在宝塔重启现有 `galweb-api`，运行目录为 `apps/api`、启动命令 `node dist/main.js`，检查 `/api/health`。EdgeOne 重新部署同版本前端。完整步骤见 [宝塔部署](https://github.com/YuyueDaV/galweb/blob/v0.2.0/docs/baota-deployment.md)及 [EdgeOne 部署](https://github.com/YuyueDaV/galweb/blob/v0.2.0/docs/edgeone-deployment.md)。

## 开放第三方登录

QQ 与 Discord 可以分别开放。在后端环境配置以下变量：

```dotenv
QQ_CLIENT_ID=
QQ_CLIENT_SECRET=
DISCORD_CLIENT_ID=
DISCORD_CLIENT_SECRET=
```

每个平台的 ID 和 Secret 必须同时填写；未配置的平台不显示登录按钮。密钥只存后端。主站为 `https://njitgal.cn` 时，在平台登记以下回调：

- QQ：`https://njitgal.cn/api/auth/oauth/qq/callback`
- Discord：`https://njitgal.cn/api/auth/oauth/discord/callback`

回调使用主站域名，不使用独立 API 子域名。正式应用的审核、测试用户和回调白名单按各平台要求配置；真实授权仍需配置完成后验收。详见 [第三方登录说明](https://github.com/YuyueDaV/galweb/blob/v0.2.0/docs/social-login.md)。

## 下载与校验

附件提供同一版本的源码：`galweb-v0.2.0-source.zip`、`galweb-v0.2.0-source.tar.gz`、`RELEASE-NOTES.md` 与 `SHA256SUMS`。Linux／宝塔可使用 tar.gz；源码包需要安装依赖和构建，不包含真实配置、已安装依赖、数据库或用户上传文件。

把附件下载到同一个目录后，可执行：

```bash
sha256sum -c SHA256SUMS
```

只下载其中一个源码包时，核对 `SHA256SUMS` 对应的一行即可。源码包不含 `.git`；需要持续使用 `git pull` 更新时，采用 Git 克隆部署。
