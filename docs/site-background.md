# 网站背景设置

管理员和超级管理员在「社区内容管理 → 站点配置 → 网站背景」设置。保存配置后，对整个网站生效；已经打开的网站在切回页面或约一分钟后获取更新，也可以手动刷新。

## 图片背景

- 默认插画为本次用户提供的完整 1920 × 1356 图片，保留比例，没有裁剪源图；桌面使用 1920 宽 WebP，手机使用 960 宽版本，分别约 421 KB 和 159 KB。
- 点击「上传背景图片」选择 JPG、PNG 或 WebP，最大 5 MB。沿用现有认证、CSRF、图片校验和 WebP 重编码服务，上传图片保存在后端上传目录。
- 上传后先显示预览，点击页面底部「保存配置」才会公开应用。可预览浅色或深色效果；「使用默认插画」恢复内置背景，也需要保存。
- 背景图被隐藏或删除时，公开配置回退到默认插画。浏览器遇到图片加载失败也会回退；默认图仍不可用则显示配置的底色。

## 纯色背景

选择「纯色背景」，可选暖白、米杏、浅绿、雾蓝、淡紫预设，也可通过颜色选择器分别设置浅色模式、深色模式下的底色。此模式不加载网站背景图片，帖子与作品自己的配图继续显示。背景类型和配色一并保存。

减少透明度偏好下，继续使用实色底，背景插画不显示。

## 存储与权限

配置存储在现有 `site_settings.data.background` JSON 字段：

```json
{
  "mode": "image",
  "assetId": null,
  "color": "#f7f6f2",
  "darkColor": "#1d201c"
}
```

`mode` 为 `image` 或 `solid`；`assetId: null` 表示内置插画。服务器只接受上传记录 ID，不接受任意文件路径或远程图片地址。新选择的上传图片必须属于当前管理员，另一位管理员可继续维护已设置的背景；普通用户不能修改站点配置。设置保存保留版本校验，避免覆盖别人刚保存的配置。

旧配置没有 `background` 时使用新默认插画；旧客户端保存文案时未提供 `background` 会保留原背景。隐藏和删除图片不会改写站点配置中的原始引用，公开读取时检查图片状态。

## 部署

无需新增数据表、数据库迁移或环境变量。先更新、构建并重启 API，再重新部署前端，使新增字段校验和后台页面同时生效。内置图位于 `apps/web/public/images/backgrounds/`，上传图片继续使用现有 `UPLOAD_DIR`。

共享默认值和配置规范化在 `packages/domain/site-background.ts`；修改后运行 `pnpm rules:sync`。
