# 实时排名与超级管理员作品维护

## 前台查看排名

进入 `/awards`，在投票阶段或已公布届次选择「实时排名」。榜单展示作品、提名人、分数和名次，同分并列；补充投票和加赛沿用服务器的正式排名规则。普通访客仍看不到他人的选票身份，署名推荐词继续公开。

投票期间每 5 秒请求本届最新数据，页面隐藏时暂停，返回页面或恢复网络时刷新；也可点击「刷新排名」。请求失败保留上次成功的数据并提示原因。已公布排名不重新计分，归档后停止自动轮询，可手动更新更正后的资料。刷新不会自动提交选票，保留尚未提交的选择和推荐词。

候选卡片同时显示分数和已有名次；搜索框可筛选候选或排名列表。新补录作品尚未得分时显示 0 分；公布后补录的作品不加入已冻结的历史名次。

## 后台维护入口

以超级管理员登录，进入 `/admin/awards` 并选择届次，打开「作品维护」。普通管理员和普通成员无法访问该入口或对应写接口；角色与账号状态在事务内重新校验。

原有「提名审核」页也保留编辑入口：超级管理员在投票、已公布和归档阶段进入该页时，默认选择「全部记录」，可直接点击「编辑作品」或「编辑本作提名」。不会因为没有待审核条目而隐藏已通过作品。

- **补录作品**：从书库选择、搜索 Bangumi，或手动填写新作品；录入实际提名人、北京时间、提名词、提名渠道和作品资料来源。补录直接作为已通过提名，适用于筹备、提名、投票、已公布和归档阶段。手动新作品会自动收录基础书库资料，封面可在「编辑作品」中补充。
- **编辑资料**：「编辑作品」可维护名称、原名、制作组、简介、封面和「作品资料来源」。名称、制作组与资料来源同步本届提名及书库资料；书库版本过期时拒绝覆盖。
- **编辑提名人**：「编辑提名人和提名渠道」进入现有批量窗口，可新增、删除、修改多位提名人、时间、提名词和渠道，保留原网站提交信息。
- **更正书库关联**：在作品编辑窗口选择正确书库条目并确认。投票开始后保留候选编号和原有选票；同届另有该作品时拒绝合并身份，避免同一张选票被重复计分。筹备与提名阶段继续支持原有的重复候选合并。
- **移除或恢复作品**：输入完整作品名称确认。移除采用逻辑删除，原始选票和审计记录保留。可筛选「已移除」并恢复该作品；恢复仅还原本次整作移除的提名，不还原此前单独删除的提名人。

「作品资料来源」用于记录官网、Bangumi、人工核对等信息；「提名渠道」记录QQ群、网站或补录来源，两者分别维护。最初提交的 `workSource` 保留供核对。

## 计票与历史结果

投票中的作品移出当前候选列表后，不再接受新投票，当前排名不包含这部作品；原始选票不删除，恢复候选后可按原票继续计分。加赛组会排除移除的候选；仍有至少两部作品的组继续投票。

**已公布和已归档届次保留原票数、名次与历史选票。** 更正名称、会社或关联书库时，仅更新结果中的作品资料，不重算分数。公布后补录的新作品仅进入资料列表，不追加历史得分。移出候选列表也不抹去已公布结果。

所有写操作记录操作者、对象与动作。维护记录携带版本摘要；资料、提名或状态已被其他管理员修改时返回 409，要求刷新后再操作。新增和维护保存在既有表的 JSON 字段中，不需要新增数据库表；部署时同步更新前后端并重启 API。

## 接口

| 方法  | 路径                                                            | 用途                                                                 |
| ----- | --------------------------------------------------------------- | -------------------------------------------------------------------- |
| GET   | `/api/admin/award-campaigns/:id/candidate-records`              | 超管查询本届活动及移除记录，返回维护摘要版本                         |
| POST  | `/api/admin/award-campaigns/:id/candidates`                     | 超管补录已通过候选及实际提名人                                       |
| PATCH | `/api/admin/award-campaigns/:id/candidates/:candidateId/status` | 传 `action: remove / restore`、`revision`、完整作品名 `confirmation` |
| PATCH | `/api/admin/award-campaigns/:id/candidates/:candidateId`        | 保存作品信息，支持 `informationSource`                               |
| PATCH | `/api/admin/award-campaigns/:id/candidates/:candidateId/work`   | 更正书库关联，携带新旧书库版本                                       |
| PATCH | `/api/admin/award-campaigns/:id/nomination-details`             | 批量维护提名人、时间、提名词与渠道                                   |

写接口均校验同源请求、登录状态及 CSRF。前台使用现有活动详情接口读取权威分数与名次，避免在浏览器内另算一套结果。
