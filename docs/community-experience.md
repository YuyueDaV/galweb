# 社区内容体验

在现有 Nuxt / NestJS / MySQL 上扩展，保留旧帖子、账号、图片和评选档案。先运行 `pnpm db:migrate` 创建新增表，再启动 API 与前端。

## 已实现入口

| 功能 | 入口与行为 |
| --- | --- |
| 发帖与草稿 | “写点什么”：Markdown 工具栏、预览、最多 12 张图片、关联作品；可选择已有 `#话题` 或输入新话题，每帖最多 5 个、每个 24 字；话题随草稿保存，也可在编辑帖子时修改。输入后自动保存当前账号草稿，关闭后保留，发布后清除。 |
| 近期话题 | 首页侧栏从最近 100 篇公开帖子汇总，按最新讨论时间排序，展示前 8 个及各自帖子数；点击精确筛选对应话题。隐藏、删除或移除标签后重新计算，其他公开帖子仍使用的话题继续保留；侧栏每 30 秒及重新进入/切回页面时更新。 |
| 帖子管理 | 管理员、超级管理员均可在 `/admin` 隐藏、恢复或确认删除帖子，作者仍可在详情页删除自己的帖子。删除后不再公开展示、筛选或计入话题，不能恢复；保留数据库记录和审核日志，操作失败会显示原因。 |
| 剧透控制 | 整篇剧透开关；`\|\|文字\|\|` 为行内剧透，独占行的 `:::spoiler` 与 `:::` 包住段落或图片；默认折叠，摘要与目录不显示被标记的内容。 |
| 回复与通知 | 帖子下可回复指定留言；帖子作者和被回复者收到站内通知，不通知自己。导航铃铛、`/notifications` 查看通知和标记已读；提名审核结果也会通知本人。 |
| 公开主页 | 点击作者头像或名称，访问 `/user/:id`；显示昵称、签名、头像、公开帖子、公开回复和主动公开的书单，不返回邮箱、用户名或密码字段。 |
| 阅读体验 | 帖子正文服务端加载；Markdown 目录、阅读进度、字号与宽屏偏好、本地图片放大；公开页面带标题、摘要和 canonical。 |
| 书单与作品关联 | `/works/:id` 记录想读、在读、已读和短评；默认私密，逐条勾选公开；`/library` 查看本人书单。关联讨论由后端分页查询。 |
| 站点配置 | `/admin/site` 管理背景图片或纯色预设、首页名称、介绍、公告、入社方式、联系方式和友链；使用版本校验避免覆盖其他管理员的新设置。背景上传与部署说明见 [网站背景设置](site-background.md)。 |
| 动态与相册 | `/admin/community` 发布或隐藏社团动态、活动日期及照片；`/community` 按时间线或相册浏览。 |

## 新增数据

- `forum_drafts`：按用户隔离的发帖草稿。
- `forum_reply_context`：回复与被回复留言的关联，禁止跨帖绑定。
- `notifications`：用户通知、目标帖子与回复、已读时间；隐藏内容不会进入通知列表。
- `site_settings`：公开站点配置与并发修改版本。
- `community_entries`：社团动态、活动日期、照片列表及显示状态。
- `user_library`：用户作品状态、短评与公开开关。

注销会清除草稿、通知和书单，并匿名化发给其他人的回复通知。公开社团记录继续保留，图片沿用现有注销与隐藏策略。

Markdown 不接受原始 HTML，脚本链接由解析器拒绝，图片仅渲染本地上传地址。图片需经过现有后端重编码与归属校验。预览复用正文渲染组件。

## 部署与检查

### 加载、主题、回复和配图体验

- 首次进入时显示轻量加载提示，页面切换采用顶部进度条；减少动态效果偏好下不旋转加载图标。账号接口请求与站点配置读取设有超时。
- 页面绘制前读取本机主题偏好，并用 `czx-theme` Cookie 为后续服务端渲染提供主题，避免等待接口后才切换深色模式。
- 回复框可选择 Emoji，在光标或选区处插入；回复仍为纯文本，保留 3000 字符限制。
- 通知列表显示当前可见回复的最多 160 字摘要；隐藏或删除的回复继续从通知中排除，不渲染摘要中的 HTML。
- 上传配图先独立保存到附件列表，不再自动插入 Markdown 链接。可点击「插入正文」调整位置或放入剧透区；已经内嵌的图片不重复展示，移除正文中的图片链接后仍作为文末附件显示。要从帖子删除配图，点击附件的「移除图片」。

本次无需数据库迁移；通知摘要需要更新并重启 API，其他功能需要重新部署前端。已发布的 v0.1.0 标签和附件保持原版本内容。

话题沿用 `forum_posts.data.tags` 和 `forum_drafts.data.tags`，无需新增话题表或执行额外迁移。接口新增公开 `GET /api/topics`、`GET /api/posts?tag=话题` 和需登录及 CSRF 校验的 `DELETE /api/posts/:id`；云端需更新并构建、重启 API，再发布前端。

生产环境设置 `NUXT_PUBLIC_SITE_URL=https://你的域名`，用于 canonical、`/sitemap.xml` 和 `/robots.txt`；不要使用默认 localhost。私有页面声明 noindex，帖子详情响应不缓存账号相关内容。

执行 `pnpm typecheck`、`pnpm test`、`pnpm build`。完整接口测试需要 `_test` 测试数据库、`AUTH_INTEGRATION=1`、`MAIL_TRANSPORT=capture`，不能指向正式库。
